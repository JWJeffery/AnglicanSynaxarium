Official badge artwork goes in this folder, named for the service:

  spotify.svg        pocket_casts.png        apple_podcasts.svg        youtube.svg        substack.png

Use the file exactly as the service supplies it (.svg, .png, .webp or .jpg both work). Do not edit, recolor or crop it.
For a version made for dark backgrounds, add a second file with -dark in the name, for example spotify-dark.svg.
A service with no file here shows as a plain text button on the home page.

Only use artwork from the service's own site or dashboard, and follow its brand rules.
